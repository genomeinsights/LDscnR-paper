The LDscnR Framework

One premise — selection locally inflates linkage disequilibrium — carried through two nested integrations and a single region-level test. This is the pipeline as it now stands, including the reconstructed null section.

LDscnR-paper Kemppainen & Guillaume 25 Aug 2026
§0Order

Running order

The steps are genuinely sequential — each consumes the previous one's output — so the numbering is the order in which they run, not a list of topics. Step 0 is a gate: if it fails, nothing downstream is interpretable.

  1. 00Detectability gatePer-chromosome tail mass; max/median ratio and CV; does the null fall silent at moderate τ_C. Decides whether the genome can be scanned at all.
  2. 01KinshipGRM from low-w_j markers; tighten the cutoff ω until λ ≥ 1.
  3. 02Association scanEMMAX and/or LFMM → one p per marker. Any test will do; the C-score only consumes the vector.
  4. 03Marker C-scoreIntegrate candidacy-and-significance over the (ρ, q*) grid.
  5. 04RegionsThreshold at τ_C, cluster on the LD graph, split at d_cap, remove below l_min.
  6. 05Null: gate, then testCheck surrogate background counts first; then location-matched region p → BH → q_R.
  7. 06Second-tier C-scoreIntegrate region significance over the (τ_C, l_min) grid → C⁽²⁾.
  8. 07ReportRanked loci with q_R (significance) and C⁽²⁾ (robustness), plus the declared grid range and null basis.
§1Premise

One premise, seen at two scales

Selection locally inflates LD. A sweep, or a barrier to gene flow, raises LD in the neighbourhood of its target, so a true signal is not an isolated peak but a block of mutually correlated markers. A false positive arising from relatedness or residual structure is isolated, with low LD to its neighbours.

The consequence that organises everything below: “LD-supported” and “clustered” are not two criteria but one footprint, seen per-marker and per-region. The marker C-score measures it at the first scale; LD clustering measures it at the second. Nothing else in the pipeline needs its own justification.

§2Marker

Local LD and the C-score

The local-LD statistic

Fit an LD-decay curve per chromosome to pairwise r² against physical distance, with decay rate a. A relative-LD level ρ ∈ (0,1) defines a neighbourhood half-width, and the statistic is the median r² inside it.

d(ρ) = ρ / [ a (1 − ρ) ]
w_j(ρ) = median{ r²_jk : |x_j − x_k| ≤ d(ρ) } Large inside a dense LD block, small for an isolated marker. Small ρ probes a tight window, large ρ a broad one.

Filter before FDR — and claim the justification

For a cell (ρ, q*) the candidate set is C(ρ,q*) = { j : w_j(ρ) ≥ Q_q*[w(ρ)] }, and Benjamini–Hochberg is applied among the candidates only, so the multiple-testing burden is carried by the candidate set rather than the whole genome.

Claim this formally

This is independent filtering in the sense of Bourgon, Gentleman & Huber (2010, PNAS): filtering before multiple-testing correction preserves type-I error control provided the filter statistic is independent of the test statistic under the null, and it increases power by shrinking the tested set. The neutral-SNP panel — association statistic flat across local-LD rank quantile — is exactly the required diagnostic.

The manuscript currently presents this as an empirical observation. Framing it as satisfying a known condition pre-empts the obvious reviewer objection that you are selecting on something correlated with significance. Add the citation.

What is swept, and what is fixed

C_j = (1 / |R||Q|) · Σρ∈R Σq*∈Q 1[ j ∈ C(ρ,q*) AND BH-q_j(ρ,q*) < α ] ∈ [0,1]

ρ and q* are natural [0,1] quantities, so integrating over them is assumption-free — the score privileges no single LD scale or candidate stringency. α has no natural range, so it is fixed at 0.05 rather than swept. Fixing it is defensible because any resulting miscalibration raises the score of null and true markers alike, and is therefore priced in by the structure-aware null in §4.

A marker scores highly only if it is repeatedly both LD-prioritised and significant. A significant-but-isolated peak scores low; an LD-supported-but-null marker scores low.

§3Region

Clustering by linkage

Because a true signal is an LD-supported block rather than a single peak, markers surviving C_j ≥ τ_C are grouped by linkage, not by physical proximity alone.

join j,k (same chromosome) when r²_jk ≥ b + (c − b)(1 − ρ_ld) b = fitted background (asymptotic) LD, c = short-range r². The threshold is decay-relative and self-calibrates per chromosome: as ρ_ld → 1 it approaches b and almost everything links; lowering it raises the bar toward c.

A region is a connected component (single linkage) of the thresholded graph within a chromosome, split wherever consecutive members are more than d_cap (default 500 kb) apart. The cap is a hard distance rather than a decay-derived one because a region's footprint is set by selection and local recombination, not by background LD — long-range r² is the rule inside inversions, so a decay-derived distance would fragment a single inversion into pieces.

The linkage graph is built once over the candidate universe { j : C_j > 0 }, so any thresholded subset clusters by graph lookup with no further genotype access. This is what makes the (τ_C, l_min) sweep in §5 affordable.

Two clustering roles — not interchangeable

ControlRoleDecides
ρ_ld, d_capBoundaryWhere one region ends — each region's shape and extent
l_minRemovalWhich regions are reported at all
Tightening the boundary controls sheds loosely linked markers off a block — but a shed piece does not vanish, it becomes its own small region. Only l_min removes it.
l_min is swept, not fixed

It is the principal false-positive control — structure noise makes small scattered clusters while a selected locus drags a linked block — but it is also consequential enough that it cannot be set by default. Eda is a 4-SNP cluster: recovered by EMMAX at l_min = 3, discarded at l_min = 10, never found by LFMM at either. Any analysis demanding ≥10 linked SNPs throws away the textbook marine–freshwater locus.

§4Null

The null, reconstructed

The previous design gave the null two jobs — calibrate τ_C by a pooled count-FDR, and assign per-region significance by a location-matched test — and ran four surrogate bases. The first job is the one that breaks, and taking it away collapses the rest.

What broke

The pooled count-FDR calibration of τ_C works only when the null is already silent. On the real data it returned τ_C = NA, l_min = 1550 for the spatial basis (FDR = 1.00 at every τ_C) and l_min = 157 for the regional permutation — while the location-matched test on that same regional null placed all 17 EMMAX regions at q_R ≤ 0.0149. Two calibration routes disagreeing by two orders of magnitude is not a result to explain; it is a procedure to remove.

One instrument

Score a region R by its summed C-mass and take as its p-value the fraction of surrogates producing a region overlapping R's genomic span with mass at least as large. BH-adjust across the discovered region set.

s_R = Σj∈R C_j
p_R = ( 1 + #{ b : s_(b,R)^null ≥ s_R } ) / ( 1 + B ) → BH → q_R Applied identically to every basis. q_R — not a per-marker Bonferroni over ~10⁵ SNPs — is the multiple-testing correction the method reports; the per-SNP burden was already carried at the C-score and size-filter stages.

The test is deliberately local. A signal confined to part of the sampled range need not be reproduced by a structure-preserving surrogate at its own locus, so a genuinely range-restricted adaptation peak — one a pooled genome-wide count would charge to structure — can still separate. It is also robust to a globally inflated null: excess null peaks are scattered, so they rarely fall on any particular observed locus.

The pooled count-FDR survives, demoted, as the calibration diagnostic below.

One gate, before any p-value is read

For each engine × basis, report the median per-surrogate count of C > 0 markers and of regions ≥ l_min, against the observed counts. A basis whose surrogates approach the observed counts is mis-specified, and its p-values are not interpretable. State this as a gate, not a remark — it is what catches both the spatial basis and the unpruned latent basis automatically, and it is what lets a mis-specified null be reported rather than quietly dropped.

Fix before publishing

The two engines are currently reported on different statistics — EMMAX as median peaks per surrogate, LFMM as pooled n(C>0) across surrogates. Recompute both as median-per-surrogate before they appear side by side.

Two bases

Specificity — home field

MVN on K for EMMAX; the latent-PC subspace for LFMM. Each engine is tested against surrogates drawn from the structure it already conditions on.

Frame this as a pipeline control, not an engine control, or a reviewer dismisses it in one line as tautological. The non-trivial content is downstream of the correction: LD blocks exist in every surrogate, so the C-score-plus-clustering machinery has every opportunity to manufacture clustered significance out of high local LD alone, regardless of phenotype. That it produces zero regions is a real test. Say plainly that this null cannot apportion signal between the ecotype contrast and population structure — that is the next basis's job.

Attribution — within-locality permutation

Shuffle the marine/freshwater label only within each of the four localities, holding each locality's ecotype composition fixed. This is the only basis carrying per-region q_R in the main text.

Caveats to state in the text

  • Norwegian stratum. 4F/1M gives C(5,1) = 5 distinct labelings, so roughly one surrogate in five reproduces the true assignment exactly, and a locus driven predominantly by the Norwegian contrast has its p floored near 0.2. This is a bounded loss of sensitivity in one stratum, not a false-positive risk — state it that way.
  • Permutation space overall is ample. C(8,2) × C(14,6) × C(5,1) × C(8,4) = 28 × 3003 × 5 × 70 = 29,429,400. B = 200 is nowhere near exhausting it.
  • Set B = 200 for both engines. The LFMM regional null currently runs at B = 96, floor 1/97 = 0.0103; EMMAX runs at 200, floor 0.005. Dropping the spatial and global bases frees roughly half the LFMM scan budget — spend it here so the two are comparable.
  • A floor is not a ranking. With every region pinned at the p-floor, q_R says “not a structure artifact”; it cannot separate the inversion from the weakest region. Ranking is C⁽²⁾'s job, and saying so explicitly is the honest division of labour.
§5Integrate

Second-tier C-score

Once the null only assigns per-region significance, τ_C stops being something to calibrate. It becomes a nuisance parameter like ρ and q* — and the pipeline already has a way to dispose of those.

U = { g ∈ G : g yields ≥ 1 region with q_R < α_R } (the usable grid)
C⁽²⁾_ℓ = (1 / |U|) · Σg∈U 1[ ∃ region R ∋ ℓ with q_R(g) < α_R ] ∈ (0,1] Normalising by |U| is what defeats cherry-picking: a locus significant only in the single cell that maximises the region count scores 1/|U| ≈ 0.

This is the marker C-score one level up — two nested grids, one consistency principle. It does not abolish parameter dependence; it lifts it from the choice of a single cell to the choice of a grid range and a null, which is a broad, reportable choice rather than a cherry-pick. Report the ranked loci together with the grid range, and treat low-C⁽²⁾ regions explicitly as parameter-sensitive.

Division of labour

q_R is the significance claim at a declared operating point. C⁽²⁾ is the robustness ranking across operating points. One table, two columns, one sentence saying which does which — otherwise the two read as redundant.

The existing “the null-quiet zone contains the high-PR ridge” material survives, but as a robustness observation about the grid being integrated over, not as a calibration step.

Cost

Surrogate scans are the only expensive step. C⁽²⁾ re-clusters cached surrogate C-vectors through the prebuilt edge graph, so the whole (τ_C, l_min) sweep costs graph lookups, not genotype access. Switch null_sig_landscape.R from null_popperm_3sp.rds to the regional null — it will also become more discriminating.

§6Support

Kinship and detectability

The LD-aware kinship

Two failure modes bracket the GRM problem. If it includes the regions under selection it absorbs their signal — a regional over-correction. If it is built from too many mutually correlated markers it deflates the whole test statistic — a global over-correction. They are not equally visible.

Build the GRM from LD-independent markers, { j : w_j < ω }, reusing the same statistic the C-score uses. Then:

  • High w_j at a signal — the expected case — means w_j-pruning excludes it, so the GRM cannot absorb it.
  • Low w_j at a signal — a point signal in a weakly linked genome — means the rule keeps it, but a marker with little local LD carries almost no structure and is nearly inert.
  • By-product — pruning high-w_j markers removes the large low-recombination blocks that would otherwise dominate the relatedness estimate.

Set ω by the genomic inflation factor: tighten until λ ≥ 1 — the largest, most powerful marker set that is not yet deflated. λ is used for this one job only. Regional absorption is invisible to it, because absorbing one high-LD region leaves the median marker untouched. w_j-pruning forecloses the regional mode by construction; λ trims the remaining excess. Residual structure a λ ≥ 1 kinship leaves behind is exactly what §4's null absorbs, so the division is clean: the kinship must only avoid deflation.

Detectability — promote it to the front

Outlier scans return candidates whether or not the data contain resolvable signal. Two truth-free quantities separate a clear-peak genome from a saturated one, using per-chromosome tail mass (markers exceeding a fixed C-score, robust to isolated high scorers in a way a per-chromosome maximum is not):

  • Between-chromosome variation. A few chromosomes towering over a near-zero bulk gives a large max/median ratio and high CV; a structure-dominated genome collapses the ratio toward one.
  • Where the null falls silent. If signal is separable the null goes quiet at moderate τ_C; if structure dominates the null stays as extreme as the observed data, so any threshold that suppresses structure suppresses everything.

This section is currently third in §Methods but is logically first: it decides whether the rest is meaningful. Move it to the front so the reader meets “can this genome be scanned?” before “how do we threshold it.”

The limitation to state: where genuinely neutral chromosomes exist they define a floor for calibration, but on a saturated genome the apparently quiet chromosomes are simply those with the weakest signal. There the threshold is unavoidably a power/FDR choice rather than a signal-versus-neutral separation, and l_min becomes the primary dial.

The test that would settle it

Rank the 90 LFMM regions by C⁽²⁾ and ask whether Kingman corroboration is monotone in that rank. If the ~21 corroborated loci sit at the top and the 78 unique ones at the bottom, you have simultaneously validated C⁽²⁾ as a credibility ranking against an external truth set and resolved the tie the permutation null cannot. If corroboration is flat in C⁽²⁾, the declining-enrichment problem has propagated to region level and the text must say so. Either outcome is publishable; the first is a much better paper.
